# Goa Market Pulse — More Pages

This ZIP contains a GitHub Pages-ready More/Settings section for Goa Market Pulse.

## Included pages

- `index.html` — More page
- `settings.html` — Settings
- `about.html` — About app
- `privacy.html` — Privacy Policy
- `contact.html` — Contact Us
- `help.html` — Help & FAQ
- `terms.html` — Terms of Use
- `data-sources.html` — Market Data Sources
- `style.css` — Shared design
- `script.js` — Small local settings behavior

## Before publishing

1. Replace every `YOUR-EMAIL@example.com` with your real support email.
2. Review the Privacy Policy against the actual permissions, APIs, analytics and third-party services used by your app.
3. Change the version number if needed.
4. Upload all files to your GitHub Pages repository.
5. Open `index.html` from your app's More bottom tab.

## Connecting from your app

If your main app is hosted in the same GitHub Pages folder, link the More tab to:

`more/index.html`

If these files are placed in the root of your repository, link to:

`index.html`

Do not add Rate the App or Share the App buttons unless you decide to implement them later.
